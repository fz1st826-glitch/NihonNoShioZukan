# 日本の塩図鑑 β版

Kotlin / Jetpack Compose製のAndroidアプリです。全国の塩を地図で探す機能を重点改修しました。有料版・アプリ内課金はなく、8つの和風テーマを無料で利用できます。

## 全国塩マップ

- 国土数値情報（行政区域データ）を基にした47都道府県GeoJSONをアプリに同梱。GeoJSONは47のFeature、47の安定コード（`PREF_CODE`）を持ち、Polygon/MultiPolygonで各島の外周を表します。
- GeoJSONはオフラインでも県境界を描画できます。道路等の背景タイルはOpenStreetMapからオンライン取得します。
- 商品数、製法、コレクションの地図モード、都道府県のタップ選択、登録数による色分け、商品リスト、選択県の強調を実装。
- ホームにも操作可能な地図を直接表示。ピンチ/ドラッグ、全国表示ボタン、位置データからの商品マーカー、近接マーカーのグリッドクラスタ表示に対応。
- 地図の海色、境界線、塗り、マーカー、OSMタイルの色調を現在のテーマに合わせます。
- 位置がソース確認できた初期商品マーカーは1地点です。製造地と原料採取地の位置が別々に公開されていないものは座標を推測しません。

## 8テーマ・無料構成

和紙風、浮世絵風、水墨画風、江戸古地図風、藍染風、桜和風、漆黒・金蒔絵風、和モダン風を収録。全テーマ無料で、DataStoreに設定を保存します。広告はGoogle公式テスト用バナーIDです。Billing依存はありません。

## 商品データ

`app/src/main/assets/salts.json`を商品カタログの正本として起動時にRoomへ同期します。商品更新はこのJSONだけを編集します。個人コレクションは別テーブルのため、カタログ行の同期で消えません。確認できない成分/検査データはnullまたは「公表データなし」とします。

## GeoJSONの出典と利用表示

同梱境界データ：Japan Prefecture Boundaries release 2026-08-04.1（EPSG:4326、47件）。国土交通省「国土数値情報（行政区域データ）」を基に処理されたデータです。出典と利用条件を`app/src/main/assets/ATTRIBUTION.txt`に記載しています。行政データの基準日は2026年1月1日です。

地図タイル：© OpenStreetMap contributors。タイルはオンライン取得です。

## GitHub ActionsでDebug APKを作る

1. ZIPを展開し、中身をGitHubリポジトリの`main`へアップロードします。
2. **Actions → Android beta APK → Run workflow**を実行します。`main`/`master`へのpushでもビルドします。
3. 成功したworkflowのArtifactsから`NihonNoShioZukan-debug-apk`をAndroidスマートフォンへ保存し、APKを開いてインストールします。
4. Androidから許可を求められた場合は、APKを開くアプリに「不明なアプリのインストール」を許可します。

この作業環境にはAndroid SDK、Gradle、エミュレーターがなく、APKは生成していません。Actionsの実行も未実施です。APKを生成したものとして扱わないでください。

## ソース内検証

`python3 scripts/validate_map_assets.py`でGeoJSONの47件・コード・座標・ポリゴン、カタログのID・出典・座標を検査できます。これは静的データ検査であり、Android実機の表示テストではありません。
